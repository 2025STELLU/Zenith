# Zenith 0.1.6-alpha：龙卷特效重做说明（基于 0.1.5-alpha）

> 目标：以写实为底，再做美术强化。旧版是一根半透明灰色塑料锥，这次从外形、材质、光照、动画、声音五个方面整体重做。
> 画质分档；体积云作为可选的最高一档，默认不开。

## 2. 外形：从物理推出来，而不是手调曲线

漏斗云不是风的边界，而是一条**等压面**：气块被吸进低压核心，膨胀降温，降到露点就凝结出可见的云。所以高度 z 处凝结的条件是

```
Δp(r) ≥ Δp_c(z) ≈ ρ g (H − z)        H = 云底高度
```

离云底越近，需要的气压亏损越小，漏斗就越粗。径向气压取兰金涡（核心内 `1 − n²/2`，核心外 `1/(2n²)`），反解后得到每个高度的漏斗半径。实现见 `TornadoShape.radiusFactor()`。

这条式子会自然给出现实中龙卷的几种形态，不需要特判：

| 强度 | 外形 |
|------|------|
| 18 m/s（弱） | 漏斗悬在半空，地面只有一团尘旋（"先见尘、后见漏斗"） |
| 24 m/s | 漏斗下到半空 |
| 30 m/s | 刚好触地，标准的锥形 |
| 42 m/s | 粗壮的楔形 |
| 形成期 | 寿命包络爬升，漏斗从云底一路"长"下来 |
| 消散期 | 漏斗收细、拉长、扭成 S 形（绳状期），最后从下往上断开 |

美术上只留了两个参数：`V_REF = 30 m/s` 和触地门槛 `0.85`。

**轴线**：移动方向上地面受摩擦拖后、顶部领先（倾斜量随移速变化），再叠加两个沿轴向上传播的摆动模态。绳状期摆幅放大到 2.5 倍左右，形成 S 形。

## 3. 网格画质（默认 HIGH）

由远到近共五个图层，每层各自排序，层与层之间 `endBatch`：

1. **云底盘**：母体超级单体的云底，半径 ≥ 220 格。中心下沉成墙云，越靠近中心越暗、并带一点青绿（雹暴下的"绿天"，美术强化），边缘淡出。贴图是各向同性的团块云纹，整体缓慢旋转。
2. **漏斗背面**：三层壳的远侧内壁。
3. **远侧云团**：比漏斗轴更远的碎屑、漏斗团块、墙云和入流碎云。
4. **漏斗正面**：三层壳的近侧外壁。
5. **近侧云团**。

**为什么看上去像云而不是塑料：**
- **三层壳视差**：暗核（细、浓、转得最快）、主壳、外层薄纱（大一圈、转得慢）。UV 随时间旋转（绕轴转），同时往上滚（上升气流），三层速度不同，就有了"在翻滚"的感觉。
- **边缘透明**：alpha 与 |N·V| 成正比，侧面掠射处变薄。真实的烟柱在轮廓处光程最短、最透明，旧版正好做反了，所以边缘是硬的。
- **云团精灵**：漏斗表面、墙云、地面碎屑、入流碎云都是随时间生灭的软云团，用来打碎轮廓。
- **光照**：向阳面亮、背阴面暗；逆光时轮廓会出现一道"银边"（前向散射）。下段混入地表颜色，取自脚下方块的地图色，所以沙漠里是黄的、平原上是褐的。
- **闪电**：每 4–12 秒在云底闪一次（双脉冲），整片云底亮起；雷声按距离延迟，大约每 40 格晚 1 秒。
- **软边着色器**：原版粒子着色器会丢弃 alpha < 0.1 的像素，导致大面积软云在 10% 透明度处被切出一圈硬边。这里换成自己的 `tornado_mesh`，只丢弃几乎完全透明的像素。

**旋转约定**：整层壳刚体旋转。如果每一圈各转各的，纹理会随时间被无限剪切，几分钟后就变成水平条纹。差速旋转的观感交给壳层之间的速度差，以及按自身高度角速度旋转的云团。

**开销**（HIGH，单个龙卷）：约 5200 个四边形，每帧在 CPU 上构建和排序。远于 192 格时自动降一档。同时最多 2 个龙卷。

## 4. 体积云画质（可选，VOLUMETRIC）

- **密度场**由漏斗（同一套等压面公式加 3D fbm 噪声）、云底与墙云（下表面起伏、外缘不规则）、地面碎屑（高斯状软团）三部分组成。
- **光照**：沿主光方向取 1 或 3 个样本估计自遮挡，用 Henyey–Greenstein 相函数做逆光银边；环境光同样受自遮挡影响，跟随原版天空亮度（夜晚、下雨、雷暴都会变暗）。闪电时云底提亮。
- **步进**：按"离最近包络的距离"自适应步长，空白处最大 28 格一步，浓处 0.9 格。首步和每一步都加抖动，消除条带。透射率低于 2% 时提前结束。
- **遮挡**：先把主帧缓冲深度 blit 到自己的纹理，再在着色器里线性化，地形会正确挡住龙卷。
- **每像素只着色一次**：代理盒只提交背向相机的面，相机在盒内时六个面全画。
- **安全退回**：检测到 Iris 光影包在用（反射调用 IrisApi，不加编译期依赖）、着色器加载失败或深度拷贝出错时，自动退回 HIGH，不会崩溃。
- **性能旋钮**：`volumetricSteps`（默认 96）、`volumetricFineLighting`（关掉后光照样本从 3 个减为 1 个，约省 40%）。

## 5. 动画连续性（TornadoTracker）

旧版直接画快照里的位置：龙卷每 5 秒瞬移一次，服务端删掉龙卷时漏斗当帧消失。现在：
- 按预测位置做最近邻配对（快照里没有 id），用相邻两次快照估算速度，每 tick 外推并指数追随，渲染时再按 partialTick 插值；
- 新出现的龙卷约 1 秒淡入，从快照中消失的约 1.5–3 秒淡出；
- 强度下降时判定为消散期，平滑过渡到绳状期；
- 动画时间每 2 小时回绕一次，避免长存档里 float 精度不足导致抖动。

顺带修掉了旧代码的一个 bug：旧版把 `getGameTimeDeltaTicks()`（帧间隔）当成 partialTick 用，导致旋转动画随帧率抖动。

## 6. 声音与碎屑（TornadoAmbience）

- **真实方块碎屑**：从漏斗下方地表取方块状态，生成原版方块碎屑粒子，绕轴高速切向运动并上抛，原版重力会把它们甩出去再落下。原版粒子构造时会把速度归一化成很小的值，所以创建后用 `setParticleSpeed` 改回来。只在 112 格内生成，数量受 `particleDensity` 控制。
- **轰鸣**：复用风声循环并降调，变成低频隆隆声，跟随最近的龙卷，320 格外听不到。
- **雷声**：与云底闪电同步，自动按距离延迟。

## 9. 已知限制与后续建议

- 网格画质下，龙卷不写深度，与水、玻璃等半透明方块交叉时的叠加顺序是近似的（与原版粒子相同）。
- 体积云目前是全分辨率步进。如果还要省，下一步可以做半分辨率加双边上采样，开销大约降到 1/3。
- 体积云模式下，云底雨幕、冰雹帘还没做，适合放进 0.3 的"局地降水"一起做。
- 台风的视觉（螺旋雨带、眼墙）可以复用这套云底盘和体积框架，作为下一个任务。

## 10. 顺带修复：N-23（P0）模组元数据没有展开

`src/main/resources/META-INF/neoforge.mods.toml` 里写的是 `${mod_id}`、`${mod_version}` 这类占位符，但 `build.gradle` 里**没有任何一步去替换它们**（ModDevGradle 不会自动做）。结果 jar 里的 mods.toml 原样带着占位符，FML 解析时报：

```
ParsingException: Invalid bare key: '${mod_id}'
File ... is not a valid mod file
```

也就是说，按仓库源码构建出来的 jar **整个模组都不会加载**。从 0.1.2 起每一版都是这样，仓库里的 `releases/zenith-1.21.1-0.1.0-alpha.jar` 也一样。这也解释了你发来的几份日志里为什么完全找不到 Zenith。

修复：`build.gradle` 增加 `processResources` 展开（与官方 MDK 的做法一致），把 `gradle.properties` 里的值填进去；同时给 `unitTest` 指明 `testedMod`。修复后 jar 内是 `modId="zenith"`、`version="0.1.6-alpha"`，单元测试 80/80 通过，专用服务端正常加载。

建议：`releases/` 里的旧 jar 删掉或者重新打包，免得别人下到不能用的版本。
