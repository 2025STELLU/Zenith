| 里程碑 | 计划 | 实际 |

**0.1.x 热修线到此可以正式收尾。** 0.1.1 文档中所有不依赖物理核心的问题都已修完。剩下的 N-20 到 N-22 加起来半天工作量，建议直接并入 0.2 的第一个提交，不必再单独发一个 0.1.5。

迭代速度很快（0.1.3 → 0.1.4 不到 14 小时），修法准确，注释也写清了"为什么"，这是很好的工程习惯。到了 0.2 要更谨慎：物理核心改动会层层传导，一处改错可能让风场整体偏离，**这时候测试比速度更重要**。

## 2. 0.2：正确性与基础设施（4–6 周）

日相位已在 0.1.4 完成，第 2 周可以集中做 L1 和 L2。

### 第 1 周：测试先行
- 建 JUnit 纯物理测试工程，先写**会失败的**测试，再改代码：
  - L1：平地 AGL 10 格处风速 / L0 风速 ∈ [0.6, 0.9]（当前 0.28）
  - L2：平地 1.6 格高处 |w| < 0.5 m/s（当前 11.2）
  - 手性：北半球低压中心东侧风指向 −Z（北）
  - 连续性：台风、尘卷风沿半径方向，相邻 0.5 格的风速差 < 1 m/s
  - 极线：NACA 0012 的 Cl(0°) = 0，cd(90°) ∈ [1.6, 2.1]
  - **回归保护**（现在就该通过）：7 处太阳因子在 dayTime 6000 ≈ 1、18000 ≈ −1；雨、雹、水沫的终速与 τ；翻译文本只用 `%s`
- GitHub Actions：构建 + 测试。仓库已在 GitHub 上，加一个 workflow 文件即可

### 第 2 周：两个 P0
1. **L1-01 AGL 分层 + 三线性插值**：完成后风声、帆船、粒子、雾的风速都会变对
2. **L2-01 地面排除 + 归一化**：完成后涡轮探针、风道读数会变对

L1 修好后，**同一周把 CoarseWindPacket 换成 v2**（见 02 文档 3.1），数据通路一次改完。

### 第 3 周：方向与边界
3. **SYS-01 手性**：地转风、台风、气旋；气旋 spin 绑定高低压；恢复可配置的科里奥利符号
4. **SYS-05 插值与边界**：域外不外推；台风外缘与眼缘、飑线、尘卷风用平滑包络
5. **SYS-03 AGL 统一**
6. 按 Zenith 自己的命名与参数体系整理 `WorldScaleDriver / BackgroundMetGrid / MesoscaleGrid` 的常量，注明每个参数的来源（N-01 剩余部分）

### 第 4 周：服务器友好
7. SYS-09 维度门控
8. SYS-10 区块安全：热源事件化、闪电只落在已加载区块、API 查询不触发区块加载
9. 海风距离场缓存
10. 配置系统

### 第 5–6 周：帆船与持久化
11. 帆船：碰撞（用 `move()` 代替 `setPos`）、横向阻力、航向约定、视风判定、客户端控制者权威
12. SYS-08 SavedData 持久化 + 由种子派生的随机源
13. DRV-01/02/03：驱动网格周期化、对流团固定宿主、龙卷改为逐点现象（Burgers–Rott 涡）

**0.2 验收**：以上测试全部通过；单人服务端平均 < 0.5 ms/tick，尖峰 < 5 ms；P0/P1 物理问题清零。
