## 0. 结论

**0.1.3 复审列出的 10 项新增问题，0.1.4 修了 9 项半，其中最重要的 N-10（日相位）完全修好。** 7 处太阳因子现在全部走 `FogModel.solarFactor()`，仓库里旧公式 `sin(2πt − π/2)` 已经一处都不剩。这条从 0.1.1 起就存在的 SYS-02 正式关闭，雾、热泡、尘卷风、海陆风、山谷风、L0 对流日变化第一次在同一个太阳时间上运行。

**有一个回归要注意（N-20，P2）：风声的室内遮蔽基本失效。** 为避免山坡上的采样点"钻进地里"，偏移点高度改成了 `max(脚高, 该点地表 + 1)`。但地表 +1 那一格**永远能看到天空**，所以 5 个采样点里有 4 个恒为"露天"。在屋里或洞穴中，音量系数从 0.1.3 的 0.25 变成了 0.85，室内外几乎没有差别。修法见第 3 节，改两行。

**物理核心除日相位外仍然没动。** L1-01（近地风约 28%）、L2-01（平地 +11.2 m/s 伪上升气流）、SYS-01（手性）等 P0/P1 问题全部仍在。热修线已经基本收尾，建议按路线图进入 0.2。

## 3. 新增问题

### N-20 【P2·回归】风声室内遮蔽基本失效

新的 `skyOpenAt()`：
```java
int y = Math.max(base.getY(), level.getHeight(Heightmap.Types.WORLD_SURFACE, x, z) + 1);
return level.canSeeSky(new BlockPos(x, y, z));
```
`getHeight(WORLD_SURFACE)` 返回该列最高非空气方块**之上**的第一格，再 +1 后必然在所有方块之上。`canSeeSky` 在 1.21.1 按天空光照是否满 15 判断，这个位置一定满足。所以只要该列已加载，4 个偏移点**恒为露天**，只有玩家脚下那 1 个点能反映遮蔽。

| 场景 | 0.1.3 开阔度 | 0.1.4 开阔度 | 音量系数 `0.25 + 0.75·开阔度` |
|------|------|------|------|
| 野外 | 1.0 | 1.0 | 1.00 → 1.00 |
| 大房子 / 地下室 | 0.0 | **0.8** | 0.25 → **0.85** |
| 洞穴深处 | 0.0 | **0.8** | 0.25 → **0.85** |
| 山坡（0.1.3 的问题） | 0.2–0.6 | 1.0 | 已修 |

**修复**（保留山坡修正，同时恢复室内判断）：
```java
int y = base.getY();
BlockPos p = new BlockPos(x, y, z);
if (!level.getBlockState(p).isAir()) {
    // 只有这个点真的埋在地里（山坡）才往上抬，最多抬 4 格
    int surface = level.getHeight(Heightmap.Types.WORLD_SURFACE, x, z);
    p = new BlockPos(x, Math.min(surface, y + 4), z);
}
return level.canSeeSky(p);
```
抬升上限 4 格：山坡上的点能露出地表，屋顶和洞顶远高于 4 格的情况仍会判为遮蔽。

### N-21 【P3】水沫的两处细节

1. **水面识别**：从玩家脚高向下找第一个水方块。玩家潜水时，脚下那一格本身就是水，`waterY` 取到的是水下的位置，水沫会在水里生成。应该找到水后继续向上找，直到上方一格不是水为止，即水柱的顶面。
2. **到顶后切换终速**：用 `yd > 0` 区分水沫和雨丝，到顶后 `yd ≤ 0`，水沫立即改按雨丝的 9 m/s、τ = 2 下落。第 6 tick 速度从 −0.016 跳到 −0.187 block/tick，下落时会突然加速。建议在构造时根据 `dy > 0` 记一个 `final boolean splash` 标志，整个生命周期都用 3.5 m/s。

### N-22 【P3】`WORLD_SURFACE` 包含树叶等方块

- **雾粒子**：在森林里，`WORLD_SURFACE` 是树冠顶，辐射雾粒子会生成在树冠上方，林下看不到雾。可以改用 `MOTION_BLOCKING_NO_LEAVES`，客户端同样维护这个高度图。
- **平流雾**：水面上的睡莲、海带顶端等方块会让 `WORLD_SURFACE − 1` 落在非水方块上，影响很小。如果要严格，可以判断该格或下面一格是不是水。

## 附录：复核时使用的数值

- 太阳因子：`solarFactor(t) = cos(2π(t − 0.25))`。t = 0 / 0.25 / 0.5 / 0.75 → 0 / 1 / 0 / −1，7 处一致
- L0 对流日变化：`0.65 + 0.35·solar`，正午 1.00、午夜 0.30
- 雾平滑：`k = 1 − e^(−1/60) = 0.0165`/tick，63% 响应 3.0 s
- 水沫：`k = 1 − e^(−1/7) = 0.133`；初速 0.15 → 5 tick 后到顶，累计升高 0.371 格；切换到雨丝参数后第 1 tick：−0.016 → −0.187 block/tick
- 风声：室内开阔度 4/5 = 0.8 → 系数 0.85（0.1.3 为 0.25）
